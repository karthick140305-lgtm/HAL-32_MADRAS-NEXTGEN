▸ HOW MERKLE VERIFICATION WORKS
1. Each search result is a leaf: SHA3(doc_id)
2. Pairs hashed upward: SHA3(left‖right)
3. Root anchored in immutable audit ledger
4. Proof path = sibling hashes root→leaf
5. Client recomputes root from leaf + proof
6. If computed_root ≠ stored_root → TAMPERED
Infrastructure operators cannot alter results without detection — even with root server access.
